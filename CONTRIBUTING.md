# Contributing

Thanks for your interest in improving Breakpoint Doctor!

1. Open an issue for nontrivial changes and include a minimal reproducer.
2. Fork the repo and create a branch with a clear name.
3. Use JavaScript ES modules; avoid introducing TypeScript files.
4. Run `npm test` and `npm run check`, adding a fixture for each detector fix.
5. Explain false-positive tradeoffs in your PR.

Please keep issue reports free of secrets, private URLs, and unredacted browser screenshots.

## Code of conduct

Be respectful, constructive and welcoming. Harassment is not tolerated.
